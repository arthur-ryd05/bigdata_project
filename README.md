# Rapprochement bancaire automatique · Gr05

**Auteurs** — REYNAUD Arthur et VAZ-SAMPAIO-DESTOT Léo.

**Prérequis prévus** — Onyxia, stockage S3, Python, DuckDB et dbt-duckdb.

**Dataset** — Journal de virements et relevé bancaire synthétiques. Le générateur sera publié dans ce dépôt. Taille totale visée des données brutes : 1 à 5 Mo. Licence, date de génération et taille mesurée à renseigner après génération.

**Problématique** — Quelle proportion des virements peut-on rapprocher automatiquement sans associer deux opérations différentes ? Quels cas doivent être transmis à la comptabilité pour vérification ?

**Chemins S3 prévus** — Dans le bucket du binôme, sous le préfixe gr05/rapprochement/ : bronze/ pour les CSV bruts, silver/ pour les données nettoyées, gold/ pour les résultats. Nom du bucket à renseigner après vérification sur Onyxia.

**Reproduction** — Projet en phase de cadrage. Les commandes de génération, d’exécution et de vérification seront ajoutées avec les composants correspondants.
